# Dashboard-de-Vendas-de-Assinaturas-Xbox


O projeto consiste na criação de uma dashboard interativa para analisar os dados de vendas de assinaturas da Xbox, transformando informações em indicadores visuais que facilitam a identificação de tendências, padrões de consumo e desempenho das vendas. A partir da análise de dados e da definição de perguntas de negócios, o objetivo é gerar insights que auxiliem na tomada de decisões estratégicas.

Uma dashboard visualmente explicativa, objetiva e bem estruturada é fundamental para apresentar as informações de forma clara e acessível, permitindo que os dados sejam compreendidos rapidamente e que as perguntas de negócios sejam respondidas com maior precisão. Assim, a análise de dados se torna uma ferramenta essencial para identificar oportunidades, melhorar resultados e apoiar decisões mais eficientes.
